Privacy policy

Effective date: October 22, 2026

This policy describes Garudaverse Backup, a personal backup setup maintained by Claudio Barros, and this informational website.

Data access and use

The local application uses Google OAuth and the drive.file permission to create, read and manage backup files created or explicitly made available to it in the owner's Google Drive. It uses that access only to store, verify, maintain and restore the owner's backups.

Encryption and credentials

Restic encrypts selected file contents and backup metadata locally before rclone uploads them to Google Drive. The owner manages the backup password and OAuth credentials locally and in a password manager. This website does not receive those credentials or the backup contents.

Sharing

The application does not sell Google user data, use it for advertising or transfer it to data brokers. Encrypted backups are stored with Google Drive as directed by the owner. Google processes account and service information under its own policies. Garudaverse Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls backup retention and deletion through the local backup tools and Google Drive. Access can be revoked in Google Account connections. Revoking access does not delete existing backups. Deleting backups and removing local credentials are separate actions controlled by the owner.

This website

These static pages contain no analytics scripts, advertising, cookies set by the site or data collection forms. GitHub Pages hosts the website and may process connection information, such as IP addresses, under the GitHub Privacy Statement.

Contact

For questions, contact the maintainer through the public repository. Do not include passwords, tokens, private documents or backup contents in a public issue.
