# Garudaverse Backup

Static homepage and privacy policy for a personal restic and rclone backup setup.

Published with GitHub Pages from the root of `main`. The site contains no scripts, dependencies, credentials or backup data.

- Privacy policy: https://claudiodtbarros.github.io/garudaverse-backup/privacy.html

Open `index.html` locally to inspect the pages.
