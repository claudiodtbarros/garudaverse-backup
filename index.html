Personal backups.
Encrypted on your device.

Garudaverse Backup is a personal backup setup maintained by Claudio Barros. It uses restic to encrypt selected files on the owner's computer and rclone to transfer the encrypted backup to the owner's Google Drive.

Google Drive access

The local command-line application uses Google OAuth authorization with the drive.file permission to create and manage its own backup files. Authorization takes place through Google's sign-in flow.

Private by design

Backup contents are encrypted locally before upload. The backup password and OAuth credentials are managed by the owner. This website provides information only; it does not run backups, offer account registration or request Google authorization.

The application is for the owner's personal use and is not a backup service offered to other people.
